05 / Trajectory

From a first Odoo module to a public toolchain.

The short version: learn the framework, learn the community, then build the tools that make both easier for the next person.

  1. 2018

    First public build

    SaldoACuba, a PHP service for Cuban mobile balances. Small, useful, and the start of shipping in public.

  2. 2019

    Odoo 12 in production

    GeniusCentral addon: connecting Odoo to a retail catalog and learning how far a real integration reaches.

  3. 2022

    Python backend

    A FastAPI project and a return to Python as the default tool for services, scripts, and glue.

  4. 2023

    OWL experiments

    A custom OWL web client and app prototypes. Nine stars on hacking-owl, and a better understanding of the frontend.

  5. 2024

    First merged OCA change

    partner_country_lang to 14.0 in partner-contact. The first time a change went through the OCA review and stayed.

  6. 2025

    OCA breadth

    Merged work in delivery, banking, POS, reporting, website, and localization. And 53 reviews of other people's pull requests so far.

  7. 2026

    Toolchain year

    ODF Agent Team v1.6.2, odoo.nvim, OSEM, and Conecta. 290 merged pull requests in total and a public toolchain that keeps growing.
